طبقات الحماية الحالية

  • تسجيل الدخول عبر Firebase Authentication.
  • التحقق من UID المحدد قبل إظهار اللوحة.
  • إرسال Firebase ID Token مع كل طلب إداري.
  • التحقق من صلاحية المسؤول داخل خادم Railway.
  • مفتاح Firebase Admin محفوظ في متغيرات Railway السرية.
