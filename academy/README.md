# NEON Academy 2060

مكتبة تعليمية وترفيهية ضخمة تعمل كجزء من مشروع NEON RIDDLE 2060 على GitHub Pages، دون npm أو عملية build.

## المحتوى الحالي

- 780 وحدة منظمة ضمن ثلاثة مستويات: تأسيسي، تطبيقي، إتقان.
- 288 وحدة معرفة ودروس.
- 360 وحدة برمجة.
- 60 وحدة اختبارات ومحاكاة.
- 72 وحدة ألعاب وتسلية.
- 29 تخصصًا ومسارًا.
- بنك أسئلة تدريبي أولي.
- أربع غرف هروب تعليمية.
- مختبر برمجة مباشر لـ HTML وCSS وJavaScript.
- قوالب وفحص تعليمي لـ Python وJava وC++ وC# وDart وSQL وGit.

## نظام الطالب

يستخدم نفس ملف اللاعب المحلي في المشروع الرئيسي، ويضيف إليه:

- XP ومستويات.
- وحدات مكتملة.
- سلسلة أيام التعلم.
- نتائج حسب المجالات.
- سجل اختبارات.
- شهادات إنجاز.
- خطة تعلم مقترحة.

الحفظ الحالي محلي في LocalStorage على الجهاز والمتصفح نفسه.

## لوحة إدارة المحتوى

المسار المحمي:

`/track2000one/studio/`

يتيح للمسؤول:

- إضافة دروس مخصصة محليًا.
- إضافة أسئلة إلى بنك محلي.
- مراجعة الطلاب الموجودين في المتصفح الحالي.
- تصدير واستيراد المحتوى بصيغة JSON.
- تصدير تقرير الطلاب بصيغة CSV.

## المرحلة القادمة

لجعل الحسابات والمحتوى مركزيًا بين جميع الأجهزة، يلزم ربط النظام بـ Firestore وقواعد أمان تعتمد على UID المسؤول، ثم نقل التقدم والدروس والأسئلة من LocalStorage إلى قاعدة البيانات.
